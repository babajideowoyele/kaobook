## Data Schema

### Tweet Fields
- `User`: Twitter display name
- `Date`: Tweet timestamp
- `Tweet`: Full tweet text
- `Binders`: Search query category
- `Permalink`: Link to original tweet
- `Retweet count`: Number of retweets
- `Likes count`: Number of likes
- `Tweet value`: TweetBinder engagement metric

### Network Data (extractable)
- Mentions: @username patterns in tweet text
- Hashtags: #tag patterns in tweet text
- Retweet relationships: RT patterns
