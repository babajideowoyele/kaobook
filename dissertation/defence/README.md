# Defence Slides

This folder contains materials for the dissertation defence presentation.

## Structure

- `slides.tex` - Main Beamer presentation
- `figures/` - Figures specific to defence slides
- `handout.pdf` - Printed handout version

## Key Sections to Cover

1. **Opening** (2 min)
   - Research context: sustainability transitions + methodological gap

2. **Problem & RQs** (3 min)
   - The cartographic gap
   - Four research questions

3. **Methodology** (5 min)
   - Design Science Research approach
   - RoleBox toolkit architecture
   - Multimodal data sources (6 modalities)

4. **Empirical Findings** (15 min)
   - EIT ecosystem overview
   - Key findings per chapter (5-9)
   - Triangulation results

5. **Contributions** (5 min)
   - Theoretical: sociotype framework
   - Methodological: multimodal cartography
   - Empirical: EIT patterns
   - Practical: open infrastructure

6. **Discussion & Implications** (5 min)
   - Propositions evaluation
   - Limitations
   - Future research

7. **Closing** (2 min)
   - Summary visualization

## Timing

Total: ~37 minutes presentation + 23 minutes Q&A = 60 minutes
